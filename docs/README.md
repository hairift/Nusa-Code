# Dokumentasi NusaCode

Dokumentasi menggunakan Bahasa Indonesia dan mencatat padanan Inggris karena
keduanya didukung oleh interpreter.

## Mulai

1. [`INSTALASI.md`](INSTALASI.md) — build dan instalasi.
2. [`BAHASA.md`](BAHASA.md) — referensi sintaks dan semantik.
3. [`STATUS_IMPLEMENTASI.md`](STATUS_IMPLEMENTASI.md) — kemampuan terverifikasi.
4. [`ARSITEKTUR.md`](ARSITEKTUR.md) — pipeline dan desain runtime.
5. [`PERALATAN.md`](PERALATAN.md) — CLI, VS Code, dan website.

## Proyek

## Label status

- **Aktif**: dapat digunakan melalui binary Cargo dan diuji.
- **Eksperimental**: tersedia, tetapi API/perilakunya belum stabil.
- **Terencana**: belum diimplementasikan dan tidak boleh dianggap tersedia.

Backend assembly dan interpreter Rust memiliki matriks fitur berbeda. Kecuali
dinyatakan lain, dokumentasi pengguna mengacu pada interpreter Rust.
