# Catatan Perubahan

Format mengikuti [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) dan
versi mengikuti Semantic Versioning setelah kontrak stabil ditetapkan.

## [Belum Dirilis]

### Ditambahkan

- Fungsi baku fungsional `dorong/push` dan `mutlak/absolute/abs`.
- Perintah Run dan Check pada extension VS Code.
- Website dokumentasi React dan TypeScript.

### Diubah

- Dokumentasi diselaraskan dengan interpreter Rust aktif.
- Website menggunakan status implementasi dan instruksi Cargo terkini.

## [0.1.0] - 2026-09-13

### Ditambahkan

- Interpreter Rust lintas platform untuk berkas `.nusa`.
- Lexer Unicode, parser recursive descent, evaluator, dan diagnostik Indonesia.
- Nilai dasar, daftar, kamus, kontrol alur, fungsi, closure, dan rekursi.
- Alias kata kunci serta fungsi baku Indonesia–Inggris.
- CLI `run`, `check`, REPL, help, dan version.
- Pengujian integrasi bahasa.
- Lisensi MIT, kebijakan komunitas, CI, dan template GitHub.
- Dukungan VS Code untuk syntax highlighting, snippet, dan ikon.
- Backend assembly dipertahankan sebagai jalur riset historis.
